Message filters

Forward only the messages you need with sender, keyword, regex, SIM and time rules.

All messages or only matching ones

In step 3 of the editor choose All messages (every SMS goes to this webhook) or Only matching messages. Each webhook has its own rules, and one SMS can match several webhooks.

Build your rules

  1. Under Match, choose All conditions (AND) or Any condition (OR).
  2. For each condition pick a Field, an Operator and a Value.
  3. + Condition adds a rule; + Group adds a nested group with its own AND/OR (up to three levels).
  4. Tick NOT — invert this condition (or group) to match the opposite.
  5. Type a real message into Try it with a sample SMS: the badge shows Would be forwarded or Would be filtered out as you edit.
FieldOperators
Sender, MessageEquals, Does not equal, Contains, Does not contain, Starts with, Ends with, Matches regex, Contains any keyword, Contains all keywords
SIM slot (1, 2), Subscription ID, Message length=, ≠, >, <, Between
Time received (HH:mm)After, Before, Between (a window like 22:00–06:00 is allowed)

Text rules ignore upper/lower case unless you tick Case-sensitive. Keyword lists take one keyword per line.

Regular expressions

  • A regex matches anywhere in the text. Use ^ and $ to match the whole text.
  • Tap Test regex under a regex condition to try it on sample text; you'll see the match and each capture group.
  • An invalid pattern can't be saved, and the error tells you what is wrong. Patterns that take too long are stopped, so a mistake can't slow the app down.
