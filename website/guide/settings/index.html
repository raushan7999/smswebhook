Settings, retention and backup

History retention, delivery defaults, logs, export and import.

SectionWhat you can change
SMSSMS listener on/off. Delete SMS after forwarding is unavailable: Android only allows the default SMS app to delete messages.
HistoryRetention: keep 7, 30 or 365 days, the newest 100 to 100,000 messages (or a custom number), or forever. Clear history.
DeliveryDefaults for new webhooks (retries, first retry delay, timeout) and Only on Wi-Fi.
LogsKeep delivery logs, Log retention (7–365 days), Clear logs.
ReliabilityBattery optimisation status and shortcut; app permissions.
Privacy & dataExport configuration, Import configuration, Clear all application data.

Retention

Old messages are removed automatically once a day and right after you change the setting. Messages still waiting to be delivered are never removed.

Move your setup to another phone

  1. Export configuration and choose Without secrets (recommended), then save the file.
  2. On the new phone, Import configuration and pick the file. Webhooks arrive disabled so you can review them.
  3. Re-enter secret header values, then enable the webhooks.

Phone backup is turned off for this app on purpose: message history and API keys should not be copied to cloud backups. Use export instead.
