Receive webhooks on your server

What the app sends, how to respond, and examples in Node.js, Python and PHP.

The request

POST /webhooks/sms HTTP/1.1
Content-Type: application/json; charset=utf-8
User-Agent: SmsWebhook/1.0.0
Authorization: Bearer <your token>
X-Idempotency-Key: 42-3-1791212400412
X-SmsWebhook-Delivery: 118

{"sender":"VM-HDFCBK","message":"Rs 5,000.00 credited to A/c XX1234 ...","timestamp":"2026-10-05T20:30:00+05:30"}
  • Always POST; the body is in the format you chose. Test requests add X-SmsWebhook-Test: true.
  • X-Idempotency-Key is the same for every retry of one message to one webhook. Store it and skip repeats.

How to respond

Your responseWhat the app does
Any 2xxMarks the message delivered. Answer fast; do heavy work later.
408, 425, 429, 5xx, timeoutRetries with increasing delays
Other 4xx (400, 401, 403, 404…)Fails without retrying; fix the cause and retry from the app
3xx redirectFails; redirects are not followed. Use the final URL

The first 4,000 characters of your response are shown in the app, so a short reply like {"received":true} helps when debugging.

Node.js (Express)

import express from "express";
const app = express();
app.use(express.json());
const seen = new Set(); // use your database in production

app.post("/webhooks/sms", (req, res) => {
  if (req.get("Authorization") !== `Bearer ${process.env.SMS_WEBHOOK_TOKEN}`) return res.sendStatus(401);
  const key = req.get("X-Idempotency-Key");
  if (seen.has(key)) return res.json({ received: true, duplicate: true });
  seen.add(key);
  const { sender, message, timestamp } = req.body;
  console.log(`SMS from ${sender} at ${timestamp}: ${message}`);
  res.json({ received: true });
});

app.listen(8080);

Python (Flask)

import os
from flask import Flask, request, jsonify, abort

app = Flask(__name__)
seen = set()  # use your database in production

@app.post("/webhooks/sms")
def sms():
    if request.headers.get("Authorization") != f"Bearer {os.environ['SMS_WEBHOOK_TOKEN']}":
        abort(401)
    key = request.headers.get("X-Idempotency-Key")
    if key in seen:
        return jsonify(received=True, duplicate=True)
    seen.add(key)
    data = request.get_json()
    print("SMS from", data["sender"], ":", data["message"])
    return jsonify(received=True)

Automation tools

n8n, Zapier, Make and similar tools give you a webhook URL in their "Webhook" trigger. Paste it into SMS Webhook, tap Test, and map the fields (sender, message, your extracted values) in the tool.

Use HTTPS with a valid certificate (for example Let's Encrypt). Self-signed certificates are rejected for your security.
