Troubleshooting

Fix the common problems: no SMS, failed deliveries, regex that doesn't match.

SMS don't appear in the app

  • Permission: Home shows No permission → tap Grant permission. If the SMS switch is greyed out in App info, use ⋮ → Allow restricted settings first.
  • Forwarding off: turn on Forward incoming SMS.
  • Force-stopped: after "Force stop", Android pauses the app until you open it again.
  • RCS / chat messages: messages marked "RCS" or "Chat" in your messaging app are not SMS and can't be forwarded.
  • Battery saving: set the app to Unrestricted battery use (see Getting started).

Messages are saved but not delivered

My server receives a message twice

This happens only if your server accepted a request but the reply was lost. Ignore repeats using X-Idempotency-Key.

My regex doesn't match

  • Use Test regex with the real message text.
  • Escape special characters: \., \(, \$.
  • Matching ignores case unless Case-sensitive is ticked.
