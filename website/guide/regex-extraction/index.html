Extract values with regex

Pull amounts, account numbers or OTPs out of the message into their own fields.

Extraction pulls a value out of the message and sends it as its own field, so your server doesn't have to parse SMS text.

  1. In step 5, tap + Add extracted field.
  2. Enter a Field name (letters, digits and _, starting with a letter), for example amount.
  3. Enter a Regex with a capture group in brackets, for example credited with Rs ([0-9,]+).
  4. Set the Capture group: 1 is the first bracketed group, 0 the whole match.
  5. Check Sample result and the values under Try it with a sample SMS.

Ready-made patterns

FieldRegexGroupGets
amount(?:Rs\.?|INR)\s?([0-9,]+(?:\.\d{2})?)15,000.00
accountA/c\s?(XX\d{4})1XX1234
otp\b(\d{6})\b1482913
upi_refUPI ref (\d{12})1627815394021

Where the value appears

  • JSON and form data: as an extra field, e.g. "amount": "5,000.00". No match gives null.
  • Templates: as {{regex.amount}}. No match gives an empty value.
