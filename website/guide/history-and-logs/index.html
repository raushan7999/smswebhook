History and delivery logs

Find any message, see what happened to it, and retry failures.

Message history

  • Messages lists every stored SMS, newest first. Search finds text in the sender or the message.
  • Filter chips: All, Delivered, Failed, Pending, Filtered.

Message detail

Tap a message to see the full text, sender, times, SIM, parts and ID, then one card per webhook with its status, attempts, HTTP status, last attempt and error. Show details reveals the exact request body and your server's response. Delivery attempts lists every request for this message.

The bin icon deletes the message from the app only; the SMS in your messaging app is not touched.

Delivery logs

Logs lists every HTTP attempt: webhook, method and URL (query values hidden), outcome, status, attempt number, duration and time. Filter by Successful or Failed, open the message, or clear all logs with the icon at the top. Header values are never logged.
