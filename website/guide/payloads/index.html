Payload formats

Choose JSON, a custom template, plain text or form data, and name your fields.

Choose a format

Body formatContent-TypeUse it when
JSONapplication/jsonMost APIs. Pick fields and rename them.
Custom JSON templateapplication/jsonYour API expects a specific shape or nesting.
Raw texttext/plainChat or logging tools that accept plain text.
Form dataapplication/x-www-form-urlencodedClassic form handlers (PHP $_POST).

Templates

With Custom JSON template or Raw text, write the body yourself with placeholders:

{
  "event": "sms.received",
  "data": {
    "from": "{{sender}}",
    "text": "{{message}}",
    "time": "{{timestamp}}",
    "amount": "{{regex.amount}}"
  }
}
  • Variables: {{sender}}, {{message}}, {{timestamp}}, {{received_at}}, {{id}}, {{sim_slot}}, {{subscription_id}}, {{device}} and {{regex.name}} for extracted values.
  • In JSON templates values are escaped for you; keep placeholders inside quotes. The app checks that the template produces valid JSON before saving.
  • Raw text example: {{sender}}: {{message}} → VM-HDFCBK: Rs 5,000.00 credited…

Request body preview under the sample SMS shows the exact body your server will receive.
