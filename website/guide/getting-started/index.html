Getting started

Install the app, allow SMS, and get the service running reliably.

Install and allow SMS

  1. Install SMS Webhook from Google Play and open it. The Home screen shows a red SMS permission required card.
  2. Tap Grant permission and allow SMS. This is the only SMS permission the app asks for: it can receive new SMS, but it can't read your inbox or send messages.
  3. The card disappears and the status changes to Service active, with SMS listener: Active and your internet status.
  4. Add your first webhook: open Webhooks and tap Add webhook. See Add a webhook.

Until you add a webhook, incoming SMS are still saved and shown as Filtered, so you can see that reception works.

If the permission is blocked

  • If you tapped Don't allow twice, the card shows Open app settings. Open it, choose Permissions → SMS → Allow.
  • On Android 13 and newer, if the app was installed from a file instead of Google Play, the SMS switch may be greyed out. In App info, tap ⋮ → Allow restricted settings, then allow SMS.

Keep it running in the background

Some phones (Samsung, Xiaomi, Oppo, Vivo and others) pause background apps to save battery. If Battery optimisation is on appears on Home, tap Battery settings and set SMS Webhook to Unrestricted / Don't optimise. On Samsung also check that the app is not in Sleeping apps.

Pause forwarding

Turn off Forward incoming SMS on Home (or SMS listener in Settings). The app then ignores new SMS completely until you turn it back on.
