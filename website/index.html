How it works

From SMS to your API in three steps

Everything happens on your phone. Messages are stored first, so nothing is lost when the network drops.

An SMS arrives

The app receives it the moment your phone does, saves it, and ignores duplicate broadcasts.

Your rules decide

Each webhook checks the sender, keywords, regex, SIM or time. One message can match several webhooks.

Your server gets JSON

The app sends an HTTPS POST in your format, records the result, and retries automatically if it fails.

What your server receives

POST /webhooks/sms HTTP/1.1
Host: payments.example.com
Content-Type: application/json; charset=utf-8
Authorization: Bearer ••••••••
X-Idempotency-Key: 42-3-1791212400412

{
  "sender": "VM-HDFCBK",
  "message": "Rs 5,000.00 credited to A/c XX1234 …",
  "timestamp": "2026-10-05T20:30:00+05:30",
  "amount": "5,000.00",
  "account": "XX1234"
}

Built for real integrations

  • Your own field names, or a custom JSON template
  • Extracted values such as amount, account or otp
  • Bearer token, Basic auth or API-key headers, encrypted on the phone
  • An idempotency key on every request, for safe de-duplication
  • Any 2xx response marks the message delivered

Developer guide

Features

Exactly the messages you need, in exactly your format

Set it up once. The app keeps forwarding in the background, even after a restart.

Smart filters

Rules for every webhook

Send all messages to one webhook and only bank credits to another. Match the sender, words in the message, a keyword list (any or all), a regular expression, the SIM slot, the length or the time of day, and combine them with AND, OR and NOT. Try your rules on a sample SMS before you save.

Payload your way

Send the format your server already understands.

  • JSON with the fields and names you choose
  • Custom JSON template with {{sender}}, {{message}}…
  • Plain text or form data
  • Regex extraction: amount, account, OTP as their own fields
  • Live preview of the exact request body

Reliable delivery

Built to deliver every message, once.

  • Saved on the phone before anything is sent
  • Waits for internet, then delivers automatically
  • Retries with increasing delays; you set the limits
  • Duplicate SMS detected; idempotency key on every request
  • Optional: send only on Wi-Fi

History and logs

See what happened to every message.

  • Search and filter: delivered, failed, pending, filtered
  • Per webhook: attempts, HTTP status, response, error
  • Delivery log with duration and time
  • Retry failed deliveries with one tap
  • Keep history for days, a number of messages, or forever

FAQ

Questions and answers

Step-by-step tutorials are in the how-to guide. Still stuck? Contact support.

Is SMS Webhook free?

Yes. There is no premium plan, subscription or in-app purchase, and the app shows no ads.

Do I need an account or a server from you?

No. There is no sign-up, and we don't run a server that receives your messages. You add the URL of your own server, automation tool or request inspector, and the app sends the SMS there.

Which messages are forwarded?

Only the ones you choose. Each webhook either receives every SMS or only messages that match its rules: sender, keywords, regex, SIM, length or time, combined with AND, OR and NOT. One SMS can go to several webhooks.

What happens when the phone is offline?

Every SMS is saved on the phone first. Deliveries wait and are sent automatically when the connection returns. Failed requests are retried with increasing delays.

Can a message be sent twice?

Duplicate SMS broadcasts are detected, and each message is sent to each webhook once. If your server accepted a request but its reply was lost, the app retries; every request carries an X-Idempotency-Key so your server can ignore the repeat.

Does it read my old messages or send SMS?

No. The app only receives new SMS as they arrive. It cannot read your inbox and never sends SMS.

Does it work with RCS or WhatsApp messages?

No. Only SMS are forwarded. RCS chat messages and messaging apps are not SMS.

Can it delete the SMS after forwarding?

No. Android only lets the default SMS app delete messages, and SMS Webhook is not an SMS app. Your messages stay in your messaging app.

Which Android versions are supported?

Android 8.0 and newer, on phones that can receive SMS. Dual-SIM phones are supported.
