<en-IN>
First release of SMS Webhook.
• Forward incoming SMS to your own HTTPS webhooks
• Multiple webhooks, each with its own filters: sender, keywords, regex, SIM, time; AND / OR / NOT
• JSON, custom JSON template, plain text or form data
• Extract values (amount, OTP, account) with regex
• Automatic retries with backoff; works offline and delivers when back online
• Message history, delivery logs, test button
• Secrets encrypted on the device. No account, no ads
</en-IN>
