# Changelog

All notable changes to SMS Webhook are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [Unreleased]
### Added
- Release kit (`release_item/`): signed build, store listing (en-IN, hi-IN), Play Console form answers, icon,
  feature graphic, 24 store screenshots, promo and teaser videos with synthesised soundtrack, privacy policy.
- Product website (`website/`): home, 11 tutorials, privacy, terms, support; generated by `tools/make_website.py`.
- Documentation set (`docs/`).

### Changed
- App icon: message bubble with the webhook symbol on brand green `#16A34A` (artwork from the BC SMS Webhook app).
- Store graphics, video and website use the green brand; the in-app UI theme remains blue.
- Editor's default sample SMS uses a realistic bank-alert format (`A/c XX1234`).

## [1.0.0] — 2026-10-07 (versionCode 10000)
### Added
- Receive SMS (multipart, Unicode, dual SIM) and store it locally with duplicate detection.
- Unlimited webhooks with independent configuration: enable/disable, edit, duplicate, delete, test.
- Filter engine: sender, message, keyword lists (ANY/ALL), regex, SIM slot, subscription, length and time of
  day; AND / OR / NOT groups up to three levels; regex time budget.
- Payload formats: JSON with custom field names, custom JSON template, raw text, form data.
- Regex extraction with capture groups.
- Custom headers with Bearer, Basic and API-key shortcuts; secret values encrypted with the Android Keystore.
- Background delivery with WorkManager: network constraints, exponential backoff, offline queueing,
  idempotency key, reconcile at start-up, optional Wi-Fi-only.
- Message history with search and status filters; message detail with per-webhook deliveries and attempts;
  delivery logs; manual retry and **Retry failed**.
- Settings: listener switch, retention by age or count, delivery defaults, log retention, export/import,
  clear data, battery-optimisation guidance, About links.
- 7-step webhook editor with live previews and draft saved across process death.
- Adaptive launcher icon; light and dark themes.

### Security
- HTTPS only in release builds; redirects not followed; backups disabled; no analytics or ads.
